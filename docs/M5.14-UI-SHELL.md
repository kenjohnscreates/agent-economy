# M5.14 UI shell — what changed and how to revert

Dan’s layout: the map is the screen. Scoreboard / bank / mayor live in a **Town data** drawer. Feed is a glass rail. Visitor opens from the white **Add your agent** header button. Agent cards are behind the **Agents** tab.

Rebased onto `main` after M9.7 (#63) so public mint, one-name-per-browser, subagents, and the 30-day quote stay.

## Files

- `apps/web/components/Shell.tsx`
- `apps/web/components/Drawer.tsx` (new)
- `apps/web/components/Controls.tsx`
- `apps/web/components/VisitorPanel.tsx` (M9.7 behavior kept)
- `apps/web/components/BankPanel.tsx` (Gateway inbound row)
- `apps/web/components/Scoreboard.tsx`, `Feed.tsx`, `MayorPanel.tsx`, `map/TownMap.tsx` (user-visible “tick” → “round”)
- `apps/web/app/globals.css`
- `apps/web/lib/gatewayInbound.ts`

Frozen `MapSlotProps` / `ZONES` / `zonePoint` were not changed.

## Revert

After this lands as a squash on `main`:

```bash
git revert --no-edit <squash-sha>
```

That restores the v0.3 right-column layout (map + Your agent + cards | scoreboard/bank/mayor/feed). Gateway inbound and “round” copy go with it; cherry-pick those files back if you still want them on the old layout.
