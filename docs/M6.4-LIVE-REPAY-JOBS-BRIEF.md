## Problem

1. Rules repay Active loans when cash > 1.5× principal. Last live 12-tick repaid cy #8 / bo #7 at t4–t5, so t7 `mark_default` had no Active non-bo loan.
2. `dee accept_job` reverts (`ESTIMATION_ERROR`) on the shared ERC-8183: subgraph `open` (unfunded) jobs, foreign providers mapped to `""` (looks unassigned), and `createJob` already sets dee as provider while `getWorld` never hydrates `assignments`.

## Design

Dry-run (`executeEnabled === false`) overlay + fixture ids **unchanged**.

**Live execute (`execute.ts`):** skip `repay` when `tick < 9` so t7 `mark_default` can still see an Active loan. `loanStatus !== Active` skip stays. Do not `markDefault` bo (existing `liveMarkDefaultTarget` + rules skip bo).

**`mapSubgraphJob`:** non-zero provider that is not a roster worker stays a non-empty sentinel (not `""`), so `providerAllowsWorker` refuses. Zero address → unassigned.

**`getWorld`:** derive `assignments` from jobs whose provider is a roster worker (acceptedAtTick = tick−1) so dee **delivers** instead of calling `setProvider` again.

**`decide` worker:** `accept_job` only on **funded** + **unassigned** (`provider === ""`) + roster client. Drop `open`. Named-provider jobs stay in assignments, not accept.

**`maybeDefault`:** skip borrower `bo` (2nd default would revokeName).
